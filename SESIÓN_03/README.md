Hablando sobre la inteligencia artificial descubri cómo estas aprenden, lo hacen desde un proceso de machine learning donde con cada búsqueda van aprendiendo, a este proceso se le conoce como machine learning, específicamente "Deep learning" donde extraen datos a partir de una optimización estadística.

> "La IA busca qué es lo más probable, no lo más veraz, ni real, ni cierto".

Lo que quiere decir que el aprendizaje de IA está repleto de sesgos de las personas detrás de ellas, sin embargo, este no es el único problema, entre otros podemos encontrar...
* El conflicto medioambiental debido a su mal uso (donde incluso vimos un artículo donde gran parte del agua que utilizan las inteligencias artificiales proceden de Chile).
* Conflicto laboral.
* Conflictos con la propiedad intelectual (PI) y autoría.

Debido a que la IA no es capaz de discernir entre información verídica y lo probable, surge un término al que se le conoce como "Alucinaciones" estas se pueden clasificar como...

| Tipo de Alucinación | Descripción |
| :--- | :--- |
| **Factual** | Afirma datos incorrectos. |
| **Referencial** | Citas inexistentes. |
| **Extrapolación** | "Completa" o "rellena" información. |

<br>

Pero antes de conocer qué inteligencias artificiales usar y cómo darles un buen uso a estas debemos conocer los modelos "Large Language Model". El LLM son máquinas de procesamiento y generación de lenguaje y estas pueden ser...

| Capacidad | Descripción |
| :--- | :--- |
| **Generación** | Producción de texto original. |
| **Compresión** | Extracción de ideas, palabras y conceptos de información. |
| **Transformación** | Resumir, expandir, cambiar tono, estructurar información. |
| **Razonamiento** | Inferencias, postura, argumentación. |
| **Conversación** | Mantener hilo de diálogo. |

<br>

A diferencia de las LLM generalistas (que pueden integrar entrenamientos masivos) las respuestas de las LLM de contexto acotado sólo están enfocadas en la información otorgada por el usuario, lo que hace que su nivel de "alucinación" sea muy bajo. Algunas de estas pueden ser:
* NotebookLM
* Claude Cowork
* Consensus
* Sci Bot

### Ingeniería de Prompts y Métodos de Consulta

¡Ahora sí! Con toda esta información podemos conocer entonces cómo hablarle a la inteligencia artificial, pues para obtener mejores resultados tendremos que usar mejores prompts.

#### Método CREA:
* **C** - Contexto
* **R** - Rol
* **E** - Expectativa
* **A** - Acotación

| Componente | Definición |
| :--- | :--- |
| **Contexto** | Define los elementos que estás trabajando, tus objetivos generales y entregables. |
| **Rol** | Asigna una especialidad, área o punto de vista. |
| **Expectativa** | Define el tipo de entregable, orden, estructura y formato. |
| **Acotación** | Límites estrictos, márgenes y no deseados en la respuesta. |

<br>

También podemos encontrar otros métodos que se ajusten más a nuestras necesidades como...

| Método de Prompting | Descripción |
| :--- | :--- |
| **Zero shot** | Solicitud puntual, sin contexto ni ideas. |
| **Few Shot** | Solicitud con instrucciones o ejemplos. |
| **Cadena de pensamiento** | Solicitud de razonamiento, paso a paso, variables y elementos necesarios para obtener el resultado. |
| **Secuenciación** | Solicitud compleja dividida en pequeños requerimientos, correlacionado con los anteriores. |
