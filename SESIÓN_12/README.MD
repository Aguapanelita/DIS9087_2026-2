Que es el tacto? 

Somatosensación . lo que llamamos tacto es un conjunto

- tacto: presión, contancto, vibración, textura 
- termocepción: tocar algo y saber si esta frio o caliente
- Nocicepcion: nos permite entender si hay dolor o hay algun daño 
- Propiocepción: dicta relación con la posición y moviemiento del cuerpo 

todas estas estan relacionadas a la vissta, pues si podemos ver algo podemos predisponer como se sienten las cosas a diferencia de si no lo estamos viendo, una pantalla tactil solo usa la primer estancia. al trabajar con todos estos factores se le llama: áptica
