¿Cómo pueden ver los computadores?

Esto es obvio, a través de una cámara, sus "ojos" pero ¿nos hemos preguntado cómo y lo que se puede lograr con esta? De esta manera nace la visión computarizada o *computer vision* (propia de todos aquellos dispositivos que permitan observar o ver a través de pixeles y nos muestre luego imágenes) lo logra con un software/programa.

Pero ¿qué es exactamente un programa (o software)? Bueno... Este es un conjunto organizado de instrucciones que un computador puede ejecutar, siguiendo reglas y normas establecidas y funciona con los siguientes elementos:

<div align="center">

Instrucción $\rightarrow$ Dato $\rightarrow$ Condición $\rightarrow$ Secuencia $\rightarrow$ Repetición

</div>

Que funcionan de la siguiente manera...

| Elemento | Descripción |
| :--- | :--- |
| **Instrucción** | Órdenes específicas para ejecutar una tarea. |
| **Dato** | Información que el programa utiliza para ejecutar una tarea. |
| **Condición** | Si/No ó Verdadero/Falso ó 1/0. |
| **Secuencia** | Orden en el que van ocurriendo estas instrucciones. |
| **Repetición** | Acción que se repite muchas veces. |

<br>
